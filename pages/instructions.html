How to Use the System

Setup and controls for hosting a game.

1. Open the two screens

  • Master Screen (master.html) — this is for the host only. It has all the controls: awarding points, flipping cards, marking wrong answers, and managing questions.
  • Player Screen (players.html) — this is what your players/audience see. Put this on a second monitor, TV, or projector.

Important: open both screens in the same browser on the same device (e.g. two tabs, or one tab mirrored/extended to a second display). The two screens sync with each other using the browser's local storage, which only works within one browser on one device — it will not sync across two separate computers or phones.

2. Master screen controls

  • Wrong Answers — the X button adds a strike; the reverse arrow undoes the last strike (up to 3 strikes).
  • Theme Music — play/stop background music (add your own audio file at audio/theme.mp3).
  • Round Actions — click a team's card to award them the current revealed points, or click "Next Round" to move to the next question.
  • Game Actions — reset the whole game, import a custom question set (JSON file), or switch back to the default questions.
  • Lock Player — hides the player screen behind a lock screen, useful between games or while setting up.

3. Running a round

  1. Click the question banner to reveal/hide the question.
  2. Click an answer card to flip it and reveal the answer.
  3. Revealed points accumulate in the center score until you award them to a team.
  4. Click a team's award button to give them the accumulated points for that round.
  5. Click "Next Round" to move on to the next question.

Using your own questions

Want to run the game with your own questions instead of the default set? Download the template below, edit it with your questions and answers, then use the Import JSON button on the master screen's Game Actions panel to load it in.

Download JSON Template

4. Renaming teams

Click directly on a team's name on the master screen to rename them. The new name updates on the player screen automatically.
